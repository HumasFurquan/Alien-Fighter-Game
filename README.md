🚀 Alien Fighter Game

A fast-paced 2D space shooter game built using HTML, CSS, and JavaScript (ES Modules) where players control a fighter plane and survive against an evolving alien UFO.

🎮 Play, survive, score, and beat your high score!

🛸 Game Features

✈️ Player-controlled fighter plane

👾 Smart alien UFO AI

Chases player horizontally

Attacks only when player is under it

🔥 Missile firing system

📈 Difficulty scaling

UFO speed increases every 10 seconds

Always slower than player for fair gameplay

💥 UFO evolution system

UFO changes appearance after every 3 hits

Total of 9 UFO stages

🌌 Animated space background

Canvas-based star movement effect

🧊 Freeze on Game Over

All movement stops

Screen blackout effect

🏆 Score system

Score = total seconds survived

Highest score saved using localStorage

🔄 Play Again button

Instantly restart the game

🎯 Controls
Keyboard Controls (PC)
Key	Action
⬅️ Arrow Left	Move Left
➡️ Arrow Right	Move Right
⬆️ Arrow Up	Move Up
⬇️ Arrow Down	Move Down
Space	Fire Missile
